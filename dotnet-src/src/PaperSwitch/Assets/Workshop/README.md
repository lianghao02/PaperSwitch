# 工坊手繪素材

本套素材於 2026-10-20 使用內建 imagegen 產生，依使用者提供的奇幻遊戲介面圖片作為風格參考，另製 PaperSwitch 專用圖集。參考圖片未納入版本庫。

## 素材與生成規格
- material-atlas.png：2 × 2 材質圖集，依序為木框羊皮紙、皮革縫線、蜂蜜色木板與苔綠皮革。四角帶黃銅包邊，紙框僅在角落少量花葉；中央留空，沒有文字或圖示。
- icon-atlas.png：4 × 4 透明圖示圖集，依序為加入文件、合併、拆分、圖片、逆轉、順轉、重新命名、空白頁、資料夾、紙簍、齒輪、選取、前移、後移、工坊書冊與放大檢視。

共同生成提示：正面平視、手繪 2D 休閒奇幻遊戲質感、暖木頭／皮革／黃銅／羊皮紙／苔綠、透明背景、無文字、無角色、無介面截圖；分格置中，材質角落保留在外側 22% 範圍，供九宮格延伸。

## 使用方式
圖集以 WPF Resource 內嵌，由 Controls/WorkshopArt.cs 在記憶體中分格與快取。原始 PNG 保持完整，不另存裁切備份。面板使用九宮格延伸，文字與文件內容獨立呈現。執行時不需要網路或外部素材路徑。
