# UI／UX 設計規範與 Design System

## 1. 應用程式版面

PaperSwitch 是 Windows WPF 桌面應用程式，不使用瀏覽器或 Web 版面。主視窗採三區固定架構：

```text
+-------------------------------------------------------------+
| 標題、版本、更新、縮圖大小、選擇檔案、批次編排工具列         |
+-------------------------------------------------------------+
|                                                             |
|                 紙張編排畫布（內部可捲動）                  |
|       空白時顯示拖放區；匯入時顯示不可點擊的進度遮罩         |
|                                                             |
+-------------------------------------------------------------+
| 紙張摘要、匯出模式、檔名、資料夾與裝訂導出                  |
+-------------------------------------------------------------+
```

## 2. 編排互動

- 支援 `Ctrl+點擊`、`Shift+點擊` 與框選多張紙張。
- 選取紙張可整包拖曳，維持相對順序；拖曳目標以插入槽明確提示。
- `Ctrl+←`／`Ctrl+→`、`Home`／`End`、`R`／`Shift+R` 與 `Delete` 提供快速編排。
- `Ctrl+Z` 復原、`Ctrl+Y` 重做手動編排動作；沒有可操作歷史時，按鈕呈停用狀態。
- 匯入與導出期間顯示置中遮罩、目前階段、檔案序號與進度列，避免誤以為程式無回應。

## 3. 視覺語言

- 底色：水彩紙米白 `#F7F4ED`
- 卡片：白色 `#FFFFFF`，邊框米黃 `#E3DDD2`
- 主要操作：陶土暖橘 `#D97736`，懸停 `#C46424`
- 次要操作與成功提示：森林苔綠 `#5B8266`
- 文字：炭焙棕黑 `#2D2825`、鉛筆灰褐 `#736B63`

按鈕、卡片與提示採柔和圓角與低對比陰影；文案使用「紙張」、「工坊」、「裝訂」等生活化語彙，避免冷冽的工程用語。
