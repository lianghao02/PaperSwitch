# UI／UX 設計規範與 Design System

## 1. 視覺主題與滿版單頁架構 (100vh Single Viewport Layout)
本工具採用 **100% 螢幕高度彈性滿版設計 (100vh)**，確保在任何螢幕解析度下皆能完美的填滿整個瀏覽器視窗，**徹底消除網頁底部大片空白**，同時設定 `overflow: hidden` 鎖定單頁，免除捲動網頁的負擔：

```
+-------------------------------------------------------------+
|                      HEADER (固定標題區)                     |
+---------------------+---------------------+-----------------+
|  📥 1. 檔案拖曳區    |  📋 2. 佇列與進度    | ⚙️ 3. 轉換設定區|
| (垂直彈性伸展拉滿)   | (佇列內部單獨捲動)   | (按鈕固定貼底)  |
+---------------------+---------------------+-----------------+
```

## 2. 三區元件垂直自適應設計
1. **📥 檔案拖曳區 (Drag & Drop Zone)**：
   - 採用 Flex `flex: 1` 垂直彈性拉滿面板高度，置中圖示與說明文字，空間充足且視覺和諧。
2. **📋 檔案佇列與目前進度區 (File Queue & Progress Area)**：
   - **佇列內部滾動 (Internal Scroll)**：設定 `min-height: 0; overflow-y: auto`。無論上傳多少檔案，僅在佇列區域內部產生捲動條，絕不撐開外層網頁。
3. **⚙️ 轉換功能設定區 (Function Settings Area)**：
   - 使用 `margin-top: auto` 將核心按鈕置底對齊，維持視覺對稱。

## 3. 色彩代碼 (Design Tokens)
- **背景主色 (`--bg-color`)**: `#0f172a` (Slate 900)
- **卡片背景 (`--card-bg`)**: `rgba(30, 41, 59, 0.75)`
- **面板背景 (`--panel-bg`)**: `rgba(15, 23, 42, 0.45)`
- **強調色 (`--accent-color`)**: `#38bdf8` (Sky 400)
- **成功色 (`--success-color`)**: `#4ade80` (Green 400)
- **警告色 (`--warning-color`)**: `#fbbf24` (Amber 400)
- **錯誤色 (`--error-color`)**: `#f87171` (Red 400)
