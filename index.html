🌟 核心特色

為公務與商用場景深度設計的轉檔利器

📊

Excel 智慧分頁處方

水平欄位強制自動縮放適應單頁寬度（FitToPagesWide = 1），右側表格絕不硬切裁離。多工作表自動獨立拆分導出為 檔名_分頁名.pdf。

⚡

多執行緒併發引擎

採用 ThreadingHTTPServer 多執行緒架構，大量檔案拖拽批次處理秒速響應，多佇列平行轉檔不卡頓。

🛡️

100% 本機資安防護

採用原生 MS Office COM 與 Pillow 引擎本機渲染，所有轉換過程完全在本機執行，檔案零外洩風險。

🖱️

拖拽批次操作介面

直覺式 Web 控制台，支援多檔同時拖拽上傳，佇列進度即時顯示，操作流暢如原生桌面應用。

🔗

PDF 智慧合併

支援多份 PDF 文件依序強健合併輸出為單一檔案，確保頁面順序與格式無損保留。

🧹

彈性手動清理

提供「清空歷史暫存檔」一鍵清理按鈕，隨心所欲整理本機硬碟，保持工作環境乾淨整潔。

🚀 快速開始

1
從 GitHub 下載

前往 lianghao02/PaperSwitch 點擊 Code → Download ZIP 或使用 git clone。

2
雙擊啟動（Windows 推薦）

直接雙擊 start.bat — 自動辨識 Python 虛擬環境並開啟 Web 控制台。

3
手動啟動

若偏好手動執行：python app.py，預設伺服器位置 http://127.0.0.1:8080。

4
拖拽檔案開始轉換

在瀏覽器中開啟控制台，將 Word / Excel / PowerPoint / 圖片直接拖拽至拖曳區，選擇輸出格式後按下轉換即可。
